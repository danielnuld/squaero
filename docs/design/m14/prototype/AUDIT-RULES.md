## What changed in the shared base (already done — use it, don't redo it)
- `theme-helmet.txt`: contrast-fixed tokens (text-faint, border-strong = control border ≥3:1, null, syntax-comment, warn, Rosa accent-text/ok). New classes: `.focus` (outline focus ring for drawing the focused element), `.focus-in` (inset ring for grid cells / tree rows), `.help` (12px help text), `.dlg-actions` (wrap the dialog's primary + cancel buttons; the order flips automatically on macOS/Linux when the root has `data-os="macos|linux"`). `:focus-visible` rule is global.
- `TitleBar`: prop `os` (windows | macos | linux) — draws Windows caption buttons + menu bar with access keys, macOS traffic lights + window title (no in-window menu), GNOME header bar (hamburger + close). Props: theme, os, notif, menuOpen, window-title.
- `Rail` is now a SIDE-PANEL SWITCHER (56px): active = explorer | history | snippets | search (these change the 248px side column) and plug | settings (bottom). Diagrama, Monitor, Notebook, Constructor, Rutinas, Triggers, Usuarios, Respaldo etc. are NOT in the Rail any more: they open from the menu Herramientas (ToolsMenu screen), the Ctrl+K palette and the connection's context menu. Never pass active="er"/"monitor"/"tools".
- `Explorer`: several connections (the focused one expanded + "Producción" collapsed, prop `second`), connection colour bar, refresh + disconnect buttons, `state` = none | connected | loading | lost (lost shows "Desconectada · Reconectar"), `tree` = db | tables | expanded | columns (columns expands clientes into its columns with PK/FK), schema level for PostgreSQL, filter with clear button and match count. Props: theme, state, tree, selected, filter, conn-name, conn-color, safe, tx, second, height.
- `DocTabs`: each tab gets its connection colour as top stripe (`color`), optional `conn` suffix ("· Producción") when more than one connection is open, `safe` lock, `running` spinner, 24px close.
- `Grid`: two-line header (name + type, PK key, FK arrow with `fk: "clientes.id"` → "integer → clientes.id"), rows 28px (24 compact), NULL as italic text, empty string as `''`, `range {r1,c1,r2,c2}` selection, `selected {r,c}` focus cell (FK arrow link appears in that row), `edited [{r,c,old}]` (amber + corner triangle; `show-old` prints the old value struck-through), `row-state {i: added|removed|changed}` → gutter glyphs + / − / ~, `loading` skeleton, `checks`, `filters` (local "Buscar" row). Pass camelCase props as kebab attributes (`row-state`, `show-old`, `show-types`).
- `SqlEditor`: fixed layout; `run-range="4-6"` highlights the statement that will run (accent band + gutter bar), `error-word`, `select-lines`, `caret-line`, `current`.
- `StatusBar`: props conn, db, color, tx, safe (neutral lock chip), lost, info (" · " separated: put selection summaries here, e.g. "3 celdas · Suma 2,230.10 · Media 743.37").
- Reference screen: `bodies/DataGrid.body` (object switcher Datos/Estructura/Índices/DDL, uniform result toolbar, Filtrar = server, "Buscar en la página" = local, in-place editing hint, raw values, pagination with total + "Contar total"). Copy it.

## Rules (each references the audit)
1. Every full-window screen: `"os"` tweak (enum windows|macos|linux, default windows) passed to TitleBar and as `data-os="{{os}}"` on the root. Dialogs wrap [Primary][Cancelar] in `<span class="dlg-actions">` (R-07, R-08, A-21).
2. Connection context is always visible (R-02, R-06): query tabs carry the connection colour; the editor run toolbar starts with a connection selector `● Ventas · main ▾` (a button styled like `.field`); "Solo lectura" is a NEUTRAL chip with a lock (never red); colours: Ventas #2f7dd6, Ventas copia #2e9e52, Producción #c4302b.
3. Running and long tasks (R-01): Ejecutar becomes "■ Detener" (btn-danger) while running; result header "Ejecutando · 00:04 · sentencia 2 de 3 · Cancelar"; grid `loading`; long operations show determinate progress + Cancelar. Never a dead screen.
4. Run scope (R-04): primary is a split button "▶ Ejecutar sentencia" (Ctrl+Intro) with menu: Sentencia actual · Selección · Script completo (Ctrl+Mayús+Intro); the editor shows `run-range` for what will run. Welcome/help texts must say the same.
5. Editor toolbar (R-19, R-20): [conexión ▾] [▶ Ejecutar sentencia ▾] [■ disabled when idle] | Formatear | Auto/Manual segmented (Manual shows Commit/Rollback) | flex | Más ⋯ (Plan, Historial, Abrir .sql Ctrl+O, Guardar .sql Ctrl+S, Guardar como snippet, Variables). Exactly one primary per toolbar/footer.
6. Grid (R-11–R-14, R-16, R-21, R-24–R-26, R-36, R-38, A-04, A-12, A-14, A-20): same toolbar as DataGrid for tables and query results; in-place editing (no "Editar" mode button): editing shows an input inside the cell; with changes the toolbar shows **Guardar (n)** primary + Descartar and the gutter glyphs; raw values (no thousand separators, booleans as true/false); range selection with summary in the status bar; "Buscar en la página" is local and always says "solo en las N filas cargadas · Filtrar en la tabla"; exports default to the whole table/query.
7. Destructive actions (R-15, R-31, A-01, A-02, A-10, A-25, A-30): btn-danger with verb + object + count ("Aplicar 3 sentencias en Ventas copia", "Eliminar tabla clientes"); confirmation that names target and consequences; in Producción/protected targets type the name; Intro never triggers the danger button; Esc cancels. Deleting a saved connection = toast "Conexión eliminada · Deshacer" or a simple dialog (not the DROP dialog). Data sync compares the whole table (say so) and confirms with counts per operation.
8. Accessibility (R-03, R-09, R-10, R-25, R-27–R-29): draw focus where relevant with `.focus`/`.focus-in`; no text under 11px; help text 12px (`.help`); targets ≥ 24×24; `<button>` for actions, `<a>` only for navigation (prototype links are fine on the control that navigates); trees/grids/menus/tabs keep their roles.
9. Language & shortcuts (R-17, R-32, R-33, R-34, A-26): Spanish key names on Windows/Linux (Ctrl, Mayús, Alt, Intro, Supr, Re Pág) formatted `Ctrl+Mayús+F`; on macOS `⇧⌘F` (only in screens that show macOS); no Ctrl+Alt shortcuts (Commit = Ctrl+Mayús+Intro? NO — use Alt+Mayús+C for Commit, Alt+Mayús+R for Rollback; multicursor Alt+Mayús+↑/↓); F5 = refrescar (re-read SELECT), never re-run writes; glossary: Revertir (rollback), Cancelar (before acting) / Cerrar (after), Refrescar, Rejilla, Restricción, Clave primaria/foránea, plurals spelled correctly (no "fila(s)").
10. Notifications (R-30, A-33): no toast for a success already visible on screen; toasts only for background tasks or other tabs; errors stay until closed; place toasts above the pagination (bottom: 64px).
11. Esc never discards work (R-37, A-36).
12. Density (R-23, R-40): rows 28/24; one density setting in Apariencia; result tabs + result toolbar may share one 36px band.
