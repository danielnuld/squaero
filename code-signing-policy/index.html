Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: signing is being set up. Releases up to and including v0.26.0 are not Authenticode-signed; they carry a SHA-256 checksum and a build-provenance attestation instead (see Verifying a download).

What is signed

Only the Windows installer published on GitHub Releases, squaero-X.Y.Z-x86.msi. It is built by the release workflow on GitHub-hosted runners, from a version tag of the public repository github.com/danielnuld/squaero, and submitted to SignPath from that same run. Nothing built on a developer's machine is signed.

The installer contains Squaero itself (squaero.exe and its database driver plugins), built by that workflow from this repository's source, together with the open-source libraries it statically links (listed in THIRD-PARTY.md). It contains no proprietary components: IBM's Informix Client SDK is not included; users who need Informix install it from IBM. Every signed file carries the product name Squaero and the release's version.

Team roles

Squaero is maintained by one person, who holds every role:

  • Committers and reviewers: Daniel Noé Núñez López (@danielnuld)
  • Approvers: Daniel Noé Núñez López (@danielnuld)

Contributions from anyone else arrive as pull requests and are reviewed by the maintainer before they are merged. A signing request is approved only for a release built from a reviewed version tag. Everyone with a role uses multi-factor authentication on GitHub and on SignPath.

Privacy policy

Squaero is a local database client. It has no telemetry and no analytics. Its network activity is:

  • The database servers and SSH hosts you configure, when you connect to them. Connection definitions, saved queries and settings stay on your computer.
  • Checking for updates. When Squaero starts, it sends one HTTPS request to GitHub (api.github.com/repos/danielnuld/squaero/releases/latest) to learn whether a newer version exists. The request carries nothing about you, your connections or your data; GitHub receives the ordinary request metadata (such as your IP address) under GitHub's privacy statement. This check is on by default and can be turned off in Settings.
  • Installing an update downloads the new installer from github.com, only when you choose to install it.
  • Links (documentation, downloads) open in your browser only when you click them.

Verifying a download

  • Integrity: sha256sum -c SHA256SUMS.txt, published with each release.
  • Provenance: gh attestation verify squaero-X.Y.Z-x86.msi --repo danielnuld/squaero proves the installer was built by the release workflow of this repository.
  • Once signing is active: the installer's Properties → Digital Signatures shows a valid signature from SignPath Foundation.
