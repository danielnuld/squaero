Six engines, and no client to install separately.

Each engine's client ships inside Squaero. Connect over TCP, TLS or an SSH tunnel.

PostgreSQL
Schemas, materialized views and TLS with server verification.
MySQL and MariaDB
Transactional editing, TLS and SSH tunnels, MySQL 8 included.
Informix
Over DRDA, without IBM's Client SDK, with readable error messages.
SQL Server
Queries, table structure and an encrypted connection.
SQLite
Open the file and edit it like any other engine.
MongoDB
find and aggregate queries, read-only.

What you do every day, without hunting through menus.

Everything on this list works today, on the engines that allow it.

SQL editor
Schema-aware completion, formatting, history, snippets and variables such as :customer.
Editable grid
Edit, insert and delete rows in a transaction, with the SQL in view before you save.
Server-side filters
Filter and sort a table without writing SQL; page through it without re-running the query.
Related data
From a cell, jump to the rows that reference it or to the one it points at.
Import and export
CSV, JSON, XLSX, XML, HTML and SQL. Pasting rows from a spreadsheet works too.
ER diagram
The tables and how they relate, from the engine's foreign keys.
Query builder
Build the SELECT with clicks and copy the SQL it writes.
Backup
Dump a database to a .sql file and restore it into another connection.
Users and monitor
Per-user permissions, live processes and slow queries.

Nothing leaves your computer

Connections, passwords, queries and history are stored on your computer. There is no Squaero server to send them to.

Actually lightweight

A C core and the system's web view. No Electron and no Java: the Windows installer is 9 MB.

Code you can read

GPL-3.0, with no per-seat licences and no paid features. Every download carries a provenance attestation.

Download Squaero

Windows

64-bit Windows 10 and 11. If you had the 32-bit version, it replaces it and keeps your connections.

Download the installer squaero-…-x64.msi

macOS

macOS 15 or later, on Apple Silicon Macs. The first time, open it from System Settings → Privacy & Security → “Open Anyway”.

Download the .dmg squaero-…-arm64.dmg

Linux

The .deb for Ubuntu 24.04 and Debian 13 or later, or the snap on any distribution. The snap does not include Informix.

Download the .deb sudo snap install squaero

Every file has its SHA-256 sum on the release page and a provenance attestation you can check with gh attestation verify.
