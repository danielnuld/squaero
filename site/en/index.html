SQL editor

An editor that understands your SQL.

It knows what every alias, CTE and subquery is, so it completes the right thing and flags the problem before you run.

  • Context-aware completion: the columns of the alias, the CTE or the subquery, and a JOIN's ON from the foreign keys.
  • Diagnostics as you type: unknown table or column, ambiguous column, UPDATE or DELETE without WHERE.
  • Go to definition, find usages and rename across the whole query.
  • Multiple cursors and templates by abbreviation.
  • Local history for every tab: go back to any version.

Work calmly, on production too.

  • safe mode

    Each connection, with its own rules

    Make it read-only, or ask for confirmation before every write. And give it a colour: production stands out in the tabs and in the strip along the window.

  • transactions

    You decide when to commit

    Manual transactions on all six engines: commit or roll back when you choose, and the app warns you if you close one that is still open.

  • connection

    If it drops, it comes back

    Keep-alive, reconnection when the connection is lost, and a Cancel that stops the query on the server, not just on screen.

Six engines, and no client to install separately.

Each engine's client ships inside Squaero. Connect over TCP, TLS or an SSH tunnel.

  • PostgreSQL

    Schemas, materialized views and TLS with server verification.

  • MySQL and MariaDB

    Transactional editing, TLS and SSH tunnels, MySQL 8 included.

  • Informix

    Over DRDA, without IBM's Client SDK, with readable error messages.

  • SQL Server

    Queries, table structure and an encrypted connection.

  • SQLite

    Open the file and edit it like any other engine.

  • MongoDB

    Queries, editing in the grid, collections and indexes, transactions and administration.

What you do every day, without hunting through menus.

  • Schema compare

    The differences between two databases and a migration script ordered by dependencies, which you review before applying.

  • Your schema in git

    Dump the DDL to a folder, one file per object, ready to version.

  • Search the data

    Find a piece of text in every table of a schema.

  • Editable grid

    Edit, insert and delete rows in a transaction, with the SQL in view before you save.

  • Pinned results

    Pin a result and compare it with the next one; plus a summary of the cells you select.

  • Transposed view

    Wide tables, row by row, with the columns running down.

  • Import and export

    CSV, JSON, XLSX, XML, HTML and SQL. Paste rows from a spreadsheet, or bring your DBeaver connections.

  • ER diagram

    The tables and how they relate, from the engine's foreign keys.

  • Users and monitor

    Permissions per database or table, live processes and slow queries.

iPhone

In your pocket, too.

The same core and the same drivers, with screens made for the phone. Passwords and SSH keys in the Keychain, behind Face ID.

Filter a table by asking: the iPhone's own model works it out and nothing leaves the device. It is optional and needs iOS 26 with Apple Intelligence.

Getting ready for the App Store.

MCP

Your databases, for your assistant.

quaero-mcp gives any MCP client access to the connections you mark, through the app's own drivers. Read-only unless you allow writes, and it runs on your computer.

quaero-mcp --connections connections.json

Download Squaero

Windows

64-bit Windows 10 and 11. If you had the 32-bit version, it replaces it and keeps your connections.

Download the installer squaero-…-x64.msi

macOS

macOS 15 or later, on Apple silicon Macs. The first time, open it from System Settings → Privacy & Security → “Open Anyway”.

Download the .dmg squaero-…-arm64.dmg

Linux

The .deb for Ubuntu 24.04 and Debian 13 or later, or the snap on any distribution. The snap does not include Informix.

Download the .deb sudo snap install squaero
